## Endpoint

```
PUT https://api.pathfinder.naivana.io/api/v1/routing/config
```

## Description

Updates the routing configuration for your organization, allowing you to change the routing strategy, enable/disable providers, and adjust priorities and weights.

**Important Notes**:
- Configuration changes are logged to the audit trail
- Cache is automatically invalidated on updates
- Advanced routing strategies require Pro tier or higher

## Request

### Headers

```http
Content-Type: application/json
Authorization: Bearer <jwt_token>
```

### Authentication

Requires JWT token from dashboard login. See the [Dashboard Authentication](/pathfinder/dashboard/authentication) guide for details.

### Rate Limiting

- Maximum 10 configuration updates per minute per organization
- Returns `Retry-After` header when rate limit is exceeded

### Request Body

```json
{
  "strategy": "round_robin",
  "enabled_providers": [
    {
      "provider": "anthropic",
      "priority": 1,
      "weight": 40,
      "enabled": true
    },
    {
      "provider": "azure",
      "priority": 2,
      "weight": 35,
      "enabled": true
    },
    {
      "provider": "google",
      "priority": 3,
      "weight": 25,
      "enabled": true
    }
  ]
}
```

### Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `strategy` | string | Yes | Routing strategy (priority, round_robin, cost_optimized, least_latency) |
| `enabled_providers` | array | Yes | List of provider configurations |

### Provider Configuration

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `provider` | string | Yes | Provider name (must be from valid providers list) |
| `priority` | integer | Yes | Priority order (1 = highest priority) |
| `weight` | integer | No | Weight for round_robin strategy (must sum to 100 across all providers) |
| `enabled` | boolean | Yes | Whether the provider is enabled |

## Routing Strategies

| Strategy | Tier Required | Description |
|----------|---------------|-------------|
| `priority` | Free | Routes requests to providers in priority order, using the next provider if the first fails |
| `round_robin` | Pro+ | Distributes requests across providers based on configured weights |
| `cost_optimized` | Pro+ | Automatically selects the provider that minimizes cost while meeting requirements |
| `least_latency` | Pro+ | Routes to the provider with the lowest latency based on historical performance |

## Valid Providers

The following provider names are supported:

- `anthropic`
- `openai`
- `google`
- `azure`
- `aws_bedrock`
- `vertex_ai`

## Error Responses

### 401 Unauthorized

```json
{
  "detail": "Missing or invalid JWT token"
}
```

### 403 Forbidden - Insufficient Tier

```json
{
  "detail": "Round Robin routing requires Pro tier or higher (current tier: free)"
}
```

### 422 Unprocessable Entity - Invalid Weights

```json
{
  "detail": "Provider weights must sum to 100 for round_robin strategy"
}
```

### 422 Unprocessable Entity - Invalid Provider

```json
{
  "detail": "Invalid provider name: 'invalid_provider'. Must be one of: anthropic, openai, google, azure, aws_bedrock, vertex_ai"
}
```

### 429 Too Many Requests

```json
{
  "detail": "Rate limit exceeded. Maximum 10 configuration updates per minute."
}
```

## Examples

### cURL - Update to Round Robin

```bash
curl -X PUT https://api.pathfinder.naivana.io/api/v1/routing/config \
  -H "Authorization: Bearer $JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "strategy": "round_robin",
    "enabled_providers": [
      {"provider": "anthropic", "priority": 1, "weight": 40, "enabled": true},
      {"provider": "azure", "priority": 2, "weight": 35, "enabled": true},
      {"provider": "google", "priority": 3, "weight": 25, "enabled": true}
    ]
  }'
```

### cURL - Update to Cost Optimized

```bash
curl -X PUT https://api.pathfinder.naivana.io/api/v1/routing/config \
  -H "Authorization: Bearer $JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "strategy": "cost_optimized",
    "enabled_providers": [
      {"provider": "anthropic", "priority": 1, "weight": 0, "enabled": true},
      {"provider": "openai", "priority": 2, "weight": 0, "enabled": true},
      {"provider": "google", "priority": 3, "weight": 0, "enabled": true}
    ]
  }'
```

### Python

```python
import requests

# Login to get JWT token
login_resp = requests.post(
    "https://api.pathfinder.naivana.io/api/v1/auth/login",
    json={"email": "user@example.com", "password": "password"}
)
token = login_resp.json()["access_token"]

# Update routing configuration
response = requests.put(
    "https://api.pathfinder.naivana.io/api/v1/routing/config",
    headers={"Authorization": f"Bearer {token}"},
    json={
        "strategy": "cost_optimized",
        "enabled_providers": [
            {"provider": "anthropic", "priority": 1, "weight": 0, "enabled": True},
            {"provider": "openai", "priority": 2, "weight": 0, "enabled": True},
            {"provider": "google", "priority": 3, "weight": 0, "enabled": True}
        ]
    }
)

config = response.json()
print(f"Updated strategy: {config['strategy']}")
print(f"Last updated: {config['last_updated']}")
```

### Node.js

```javascript
// Login to get JWT token
const loginResp = await fetch('https://api.pathfinder.naivana.io/api/v1/auth/login', {
  method: 'POST',

    email: 'user@example.com',
    password: 'password'
  })
});

const { access_token } = await loginResp.json();

// Update routing configuration

    ]
  })

const config = await response.json();
```

## Audit Logging

All configuration changes are automatically logged to the `routing_config_change_log` table with the following information:

| Field | Description |
|-------|-------------|
| `organization_id` | Organization making the change |
| `changed_by` | User ID who made the change |
| `change_type` | Type of change: `config_created`, `strategy_change`, `provider_priority_change` |
| `previous_value` | Previous configuration (JSON) |
| `new_value` | New configuration (JSON) |
| `client_ip` | Client IP address |
| `user_agent` | Client user agent |
| `created_at` | Timestamp of the change |

## Best Practices

### Weight Configuration for Round Robin

When using `round_robin` strategy, ensure weights sum to 100:

```json
{
  "strategy": "round_robin",
  "enabled_providers": [
    {"provider": "anthropic", "priority": 1, "weight": 50, "enabled": true},
    {"provider": "openai", "priority": 2, "weight": 30, "enabled": true},
    {"provider": "google", "priority": 3, "weight": 20, "enabled": true}
  ]
}
```

### Priority Configuration

Lower priority numbers indicate higher priority:

```json
{
  "strategy": "priority",
  "enabled_providers": [
    {"provider": "anthropic", "priority": 1, "weight": 0, "enabled": true},  // Tried first
    {"provider": "openai", "priority": 2, "weight": 0, "enabled": true},     // Tried second
    {"provider": "google", "priority": 3, "weight": 0, "enabled": true}      // Tried third
  ]
}
```
