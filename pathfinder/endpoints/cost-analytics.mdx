## Endpoint

```
GET https://api.pathfinder.naivana.io/api/v1/routing/analytics/cost-by-provider
```

## Description

Retrieves detailed cost analytics aggregated by provider for a specified time range. This endpoint provides insights into spending patterns, cost savings from multi-provider routing, and per-provider efficiency metrics.

**Key Metrics**:
- Total cost per provider
- Request volume and token usage
- Average latency and cost per request
- Estimated savings vs. single-provider usage

## Request

### Headers

```http
Authorization: Bearer <jwt_token>
```

### Authentication

Requires JWT token from dashboard login. See the [Dashboard Authentication](/pathfinder/dashboard/authentication) guide for details.

### Query Parameters

| Parameter | Type | Default | Required | Description |
|-----------|------|---------|----------|-------------|
| `time_range` | string | `30d` | No | Time range for analytics: `7d`, `30d`, or `90d` |


### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `providers` | array | Per-provider cost and usage analytics |
| `time_range` | string | Time range used for the analytics query |
| `total_cost_usd` | number | Total cost across all providers in USD |
| `estimated_single_provider_cost_usd` | number | Estimated cost if using only the most expensive provider |
| `savings_usd` | number | Cost savings from multi-provider routing in USD |
| `savings_percentage` | number | Percentage savings compared to single-provider usage |

### Provider Analytics Fields

| Field | Type | Description |
|-------|------|-------------|
| `provider` | string | Provider name |
| `total_cost_usd` | number | Total cost for this provider in USD |
| `total_requests` | integer | Total number of requests routed to this provider |
| `total_input_tokens` | integer | Total input tokens processed |
| `total_output_tokens` | integer | Total output tokens generated |
| `avg_latency_ms` | number | Average request latency in milliseconds |
| `cost_per_request` | number | Average cost per request in USD |

## Error Responses

```json
{
  "detail": "Missing or invalid JWT token"

```



### Python - Analyze Costs

```python
import requests

# Login to get JWT token
login_resp = requests.post(
    "https://api.pathfinder.naivana.io/api/v1/auth/login",
    json={"email": "user@example.com", "password": "password"}
)
token = login_resp.json()["access_token"]

# Get cost analytics for the last 30 days
response = requests.get(
    "https://api.pathfinder.naivana.io/api/v1/routing/analytics/cost-by-provider",
    headers={"Authorization": f"Bearer {token}"},
    params={"time_range": "30d"}
)

analytics = response.json()

# Display cost summary
print(f"Total Cost: ${analytics['total_cost_usd']:.2f}")
print(f"Estimated Single-Provider Cost: ${analytics['estimated_single_provider_cost_usd']:.2f}")
print(f"Savings: ${analytics['savings_usd']:.2f} ({analytics['savings_percentage']:.1f}%)")

print("\nPer-Provider Breakdown:")
for provider in analytics['providers']:
    print(f"\n{provider['provider'].upper()}:")
    print(f"  Total Cost: ${provider['total_cost_usd']:.2f}")
    print(f"  Requests: {provider['total_requests']:,}")
    print(f"  Cost/Request: ${provider['cost_per_request']:.5f}")
    print(f"  Avg Latency: {provider['avg_latency_ms']:.1f}ms")
    print(f"  Input Tokens: {provider['total_input_tokens']:,}")
    print(f"  Output Tokens: {provider['total_output_tokens']:,}")
```

### Python - Find Most Cost-Efficient Provider

```python
import requests

# Get JWT token (omitted for brevity)
token = "your_jwt_token"

response = requests.get(
    "https://api.pathfinder.naivana.io/api/v1/routing/analytics/cost-by-provider",
    headers={"Authorization": f"Bearer {token}"},
    params={"time_range": "30d"}
)

analytics = response.json()

# Sort providers by cost per request
sorted_providers = sorted(
    analytics['providers'],
    key=lambda x: x['cost_per_request']
)

print("Providers by Cost Efficiency:")
for i, provider in enumerate(sorted_providers, 1):
    print(f"{i}. {provider['provider']}: ${provider['cost_per_request']:.5f}/request")
```

## Use Cases

### ROI Analysis

Calculate return on investment from using Pathfinder:

```python
def calculate_roi(token, time_range="30d"):
    response = requests.get(
        "https://api.pathfinder.naivana.io/api/v1/routing/analytics/cost-by-provider",
        headers={"Authorization": f"Bearer {token}"},
        params={"time_range": time_range}
    )

    analytics = response.json()

    # Assuming Pathfinder costs $X/month
    pathfinder_monthly_cost = 50.00  # Example cost

    # Annualize savings based on time range
    days = int(time_range.replace('d', ''))
    annualized_savings = (analytics['savings_usd'] / days) * 365

    annual_roi = ((annualized_savings - (pathfinder_monthly_cost * 12)) /
                  (pathfinder_monthly_cost * 12)) * 100

    print(f"Annual Savings: ${annualized_savings:.2f}")
    print(f"Annual Pathfinder Cost: ${pathfinder_monthly_cost * 12:.2f}")
    print(f"ROI: {annual_roi:.1f}%")

    return annual_roi
```

### Budget Alerts

Monitor spending and set alerts:

```python
def check_budget_threshold(token, budget_limit_usd, time_range="30d"):
    response = requests.get(
        "https://api.pathfinder.naivana.io/api/v1/routing/analytics/cost-by-provider",
        headers={"Authorization": f"Bearer {token}"},
        params={"time_range": time_range}
    )

    analytics = response.json()
    total_cost = analytics['total_cost_usd']

    if total_cost > budget_limit_usd:
        print(f"WARNING: Budget exceeded!")
        print(f"Spent: ${total_cost:.2f} / Budget: ${budget_limit_usd:.2f}")
        print(f"Overage: ${total_cost - budget_limit_usd:.2f}")

        # Identify highest cost provider
        highest_cost_provider = max(analytics['providers'],
                                    key=lambda x: x['total_cost_usd'])
        print(f"Highest cost provider: {highest_cost_provider['provider']} "
              f"(${highest_cost_provider['total_cost_usd']:.2f})")
    else:
        remaining = budget_limit_usd - total_cost
        print(f"Budget OK: ${total_cost:.2f} / ${budget_limit_usd:.2f}")
        print(f"Remaining: ${remaining:.2f}")

# Example usage
check_budget_threshold(token, budget_limit_usd=200.00, time_range="30d")
```
