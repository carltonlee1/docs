## Endpoint

```
GET https://api.pathfinder.naivana.io/api/v1/routing/providers/health
```

## Description

Retrieves real-time health status for all configured providers, including circuit breaker states, latency metrics, error rates, and availability status. This endpoint is useful for monitoring provider reliability and making informed routing decisions.

**Key Features**:
- Real-time circuit breaker status
- Latency percentiles (P50, P95, P99)
- 24-hour error rate tracking
- Last success/failure timestamps

## Request

### Headers

```http
Authorization: Bearer <jwt_token>
```

### Authentication

Requires JWT token from dashboard login. See the [Dashboard Authentication](/pathfinder/dashboard/authentication) guide for details.

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `providers` | array | List of provider health metrics |
| `timestamp` | string | ISO 8601 timestamp when health data was collected |

### Provider Health Fields

| Field | Type | Description |
|-------|------|-------------|
| `provider` | string | Provider name |
| `status` | string | Overall health status (see Provider Status Values below) |
| `circuit_state` | string | Circuit breaker state (see Circuit Breaker States below) |
| `failure_count` | integer | Number of recent failures |
| `success_count` | integer | Number of recent successes |
| `latency_p50_ms` | number | 50th percentile latency in milliseconds |
| `latency_p95_ms` | number | 95th percentile latency in milliseconds |
| `latency_p99_ms` | number | 99th percentile latency in milliseconds |
| `error_rate_24h` | number | Error rate over the last 24 hours (0.0-1.0) |
| `last_failure_at` | string | ISO 8601 timestamp of last failure (null if no recent failures) |
| `last_success_at` | string | ISO 8601 timestamp of last success |

## Provider Status Values

| Status | Description | Criteria |
|--------|-------------|----------|
| `available` | Provider is healthy and fully operational | Circuit closed, error rate < 5% |
| `degraded` | Provider experiencing issues but still usable | Circuit half-open or error rate 5-20% |
| `unavailable` | Provider is not operational | Circuit open or error rate > 20% |

## Circuit Breaker States

The circuit breaker pattern protects against cascading failures by monitoring provider health and temporarily blocking requests to unhealthy providers.

| State | Description | Behavior |
|-------|-------------|----------|
| `closed` | Normal operation | All requests are allowed through |
| `half_open` | Testing recovery | Limited requests allowed to test if provider has recovered |
| `open` | Provider unavailable | All requests blocked, waiting for recovery period |

```bash
curl https://api.pathfinder.naivana.io/api/v1/routing/providers/health \
```

### Python

```python
import requests

# Login to get JWT token
login_resp = requests.post(
    "https://api.pathfinder.naivana.io/api/v1/auth/login",
    json={"email": "user@example.com", "password": "password"}
)
token = login_resp.json()["access_token"]

# Get provider health status
response = requests.get(
    "https://api.pathfinder.naivana.io/api/v1/routing/providers/health",
    headers={"Authorization": f"Bearer {token}"}
)

health_data = response.json()

# Display health summary
for provider in health_data['providers']:
    print(f"\n{provider['provider'].upper()}:")
    print(f"  Status: {provider['status']}")
    print(f"  Circuit State: {provider['circuit_state']}")
    print(f"  P50 Latency: {provider['latency_p50_ms']:.1f}ms")
    print(f"  P95 Latency: {provider['latency_p95_ms']:.1f}ms")
    print(f"  Error Rate (24h): {provider['error_rate_24h'] * 100:.2f}%")
    print(f"  Success Count: {provider['success_count']}")
```

### Python - Filter Available Providers

```python
import requests

# Login and get health data
login_resp = requests.post(
    "https://api.pathfinder.naivana.io/api/v1/auth/login",
    json={"email": "user@example.com", "password": "password"}
)
token = login_resp.json()["access_token"]

response = requests.get(
    "https://api.pathfinder.naivana.io/api/v1/routing/providers/health",
    headers={"Authorization": f"Bearer {token}"}
)

health_data = response.json()

# Filter to only available providers
available_providers = [
    p for p in health_data['providers']
    if p['status'] == 'available' and p['circuit_state'] == 'closed'
]

print(f"Available providers: {[p['provider'] for p in available_providers]}")
```

### Node.js

```javascript
// Login to get JWT token
const loginResp = await fetch('https://api.pathfinder.naivana.io/api/v1/auth/login', {
```

### Node.js - Find Lowest Latency Provider

```javascript
// Get health data (authentication steps omitted for brevity)
const response = await fetch('https://api.pathfinder.naivana.io/api/v1/routing/providers/health', {
  headers: { 'Authorization': `Bearer ${access_token}` }
});

const healthData = await response.json();

// Find provider with lowest P50 latency that's available
const availableProviders = healthData.providers.filter(
  p => p.status === 'available' && p.circuit_state === 'closed'
);

const lowestLatency = availableProviders.reduce((prev, current) =>
  (prev.latency_p50_ms < current.latency_p50_ms) ? prev : current
);

console.log(`Lowest latency provider: ${lowestLatency.provider} (${lowestLatency.latency_p50_ms}ms)`);
```

## Caching

Provider health data is cached in Redis for 30 seconds to balance freshness with performance. The cache is automatically invalidated when new health metrics are recorded.

## Use Cases

### Monitoring Provider Reliability

Use this endpoint to monitor your providers' health over time:

```python
import requests
import time

def monitor_provider_health(token, interval_seconds=60):
    while True:
        response = requests.get(
            "https://api.pathfinder.naivana.io/api/v1/routing/providers/health",
            headers={"Authorization": f"Bearer {token}"}
        )

        health_data = response.json()

        # Check for degraded or unavailable providers
        issues = [
            p for p in health_data['providers']
            if p['status'] in ['degraded', 'unavailable']
        ]

        if issues:
            print(f"WARNING: {len(issues)} provider(s) experiencing issues:")
            for provider in issues:
                print(f"  - {provider['provider']}: {provider['status']}")
        else:
            print("All providers healthy")

        time.sleep(interval_seconds)
```

### Dynamic Routing Based on Health

Combine health data with routing decisions:

```python
def get_healthiest_provider(token):
    response = requests.get(
        "https://api.pathfinder.naivana.io/api/v1/routing/providers/health",
        headers={"Authorization": f"Bearer {token}"}
    )

    health_data = response.json()

    # Filter to available providers and sort by error rate
    healthy_providers = sorted(
        [p for p in health_data['providers'] if p['status'] == 'available'],
        key=lambda x: (x['error_rate_24h'], x['latency_p50_ms'])
    )

    return healthy_providers[0]['provider'] if healthy_providers else None
```
