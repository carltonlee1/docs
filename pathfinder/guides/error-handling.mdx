## Error Response Format

All errors follow a consistent JSON structure:

```json
{
  "error": {
    "message": "Human-readable error description",
    "type": "error_category",
    "code": "machine_readable_code",
    "param": "field_name"
  }
}
```

| Field | Description |
|-------|-------------|
| `message` | Human-readable error description |
| `type` | Error category (e.g., `invalid_request`, `authentication_error`) |
| `code` | Machine-readable error code for programmatic handling |
| `param` | The request parameter that caused the error (optional) |

See [Error Schemas](/docs/api/schemas/error-schemas) for complete reference.

## HTTP Status Codes

### 400 Bad Request

Invalid request parameters or malformed request body.

**Example: Invalid Model**
```json
{
  "error": {
    "message": "Model 'fake-model-xyz-123' not found",
    "type": "invalid_request",
    "code": "invalid_model"
  }
}
```

**Common Causes:**
- Specifying a model that does not exist
- Invalid JSON in request body
- Malformed parameter values

**How to Handle:**
```python
try:
    response = requests.post(url, json=payload)
    response.raise_for_status()
except requests.HTTPError as e:
    if e.response.status_code == 400:
        error = e.response.json().get("error", {})
        if error.get("code") == "invalid_model":
            # Fall back to auto model selection
            payload["model"] = "auto"
            response = requests.post(url, json=payload)
```

### 401 Unauthorized

Authentication failed or credentials missing.

**Example: Invalid API Key**
```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

**Example: Expired API Key**
```json
{
  "error": {
    "message": "API key has expired",
    "type": "invalid_api_key",
    "code": "api_key_expired"
  }
}
```

**Example: Invalid JWT Token**
```json
{
  "error": {
    "message": "Invalid or expired token",
    "type": "authentication_error",
    "code": "invalid_token"
  }
}
```

**Common Causes:**
- Missing Authorization header
- Incorrect API key
- Expired API key or JWT token
- Revoked API key

**How to Handle:**
```python
try:
    response = requests.post(url, headers={"X-API-Key": api_key}, json=payload)
    response.raise_for_status()
except requests.HTTPError as e:
    if e.response.status_code == 401:
        error = e.response.json().get("error", {})
        code = error.get("code")

        if code == "api_key_expired":
            # Generate new API key from dashboard
            raise Exception("API key expired. Please generate a new key.")

        if code == "invalid_token":
            # Refresh JWT token
            refresh_token()
            retry_request()
```

### 403 Forbidden

Valid credentials but insufficient permissions.

**Example:**
```json
{
  "error": {
    "message": "Insufficient permissions to access this resource",
    "type": "forbidden",
    "code": "insufficient_permissions"
  }
}
```

**Common Causes:**
- API key does not have required scopes
- User role does not have required permissions
- Accessing organization-specific resources without membership

**How to Handle:**
```python
if e.response.status_code == 403:
    # Check API key scopes or user permissions
    raise Exception("Access denied. Check API key scopes or user permissions.")
```

### 404 Not Found

Requested resource does not exist.

**Example:**
```json
{
  "error": {
    "message": "Resource not found",
    "type": "not_found",
    "code": "resource_not_found"
  }
}
```

**Common Causes:**
- Invalid endpoint URL
- Resource ID does not exist
- Resource was deleted

**How to Handle:**
```python
if e.response.status_code == 404:
    # Resource doesn't exist - handle gracefully
    return None
```

### 422 Validation Error

Request failed validation.

**Example: Missing Messages**
```json
{
  "detail": [
    {
      "loc": ["body", "messages"],
      "msg": "field required",
      "type": "value_error.missing"
    }
  ]
}
```

**Example: Empty Messages Array**
```json
{
  "detail": [
    {
      "loc": ["body", "messages"],
      "msg": "ensure this value has at least 1 item",
      "type": "value_error.list.min_items"
    }
  ]
}
```

**Common Causes:**
- Missing required fields
- Invalid field types
- Values outside allowed ranges
- Empty arrays when at least one item required

**How to Handle:**
```python
if e.response.status_code == 422:
    errors = e.response.json().get("detail", [])
    for error in errors:
        field = ".".join(str(x) for x in error.get("loc", []))
        message = error.get("msg")
        print(f"Validation error in {field}: {message}")
```

### 429 Rate Limited

Too many requests in a given time period.

**Example:**
```json
{
  "error": {
    "message": "Rate limit exceeded. Please retry after 60 seconds.",
    "type": "rate_limit_exceeded",
    "code": "rate_limited"
  }
}
```

**Response Headers:**
```
X-RateLimit-Limit: 100
X-RateLimit-Remaining: 0
X-RateLimit-Reset: 1704067260
Retry-After: 60
```

**Common Causes:**
- Exceeding requests per minute limit
- Exceeding requests per day limit
- Login attempt rate limiting (5 attempts per 15 minutes)

**How to Handle:**
```python
import time

def request_with_retry(url, payload, max_retries=3):
    for attempt in range(max_retries):
        try:
            response = requests.post(url, json=payload)
            response.raise_for_status()
            return response.json()
        except requests.HTTPError as e:
            if e.response.status_code == 429:
                retry_after = int(e.response.headers.get("Retry-After", 60))
                print(f"Rate limited. Waiting {retry_after} seconds...")
                time.sleep(retry_after)
            else:
                raise
    raise Exception("Max retries exceeded")
```

### 500 Internal Server Error

An unexpected error occurred on the server.

**Example:**
```json
{
  "error": {
    "message": "An internal error occurred",
    "type": "internal_error",
    "code": "internal_error"
  }
}
```

**Common Causes:**
- Server-side bug
- Database connection failure
- Unexpected exception

**How to Handle:**
```python
if e.response.status_code == 500:
    # Log the error and retry with exponential backoff
    correlation_id = e.response.headers.get("X-Correlation-ID")
    print(f"Server error. Correlation ID: {correlation_id}")

    # Retry with exponential backoff
    for attempt in range(3):
        time.sleep(2 ** attempt)
        try:
            return retry_request()
        except:
            continue
    raise Exception("Server error persists. Contact support.")
```

### 502 Bad Gateway

Error communicating with upstream provider.

**Example:**
```json
{
  "error": {
    "message": "Provider returned an error: Connection refused",
    "type": "provider_error",
    "code": "provider_unavailable"
  }
}
```

**Common Causes:**
- LLM provider is down
- Network connectivity issue
- Provider rate limiting

**How to Handle:**
```python
if e.response.status_code == 502:
    # Try with a different provider preference
    payload["routing"] = {"exclude_providers": ["openai"]}
    return retry_request()
```

### 503 Service Unavailable

The service is temporarily unavailable.

**Example:**
```json
{
  "error": {
    "message": "Service temporarily unavailable",
    "type": "service_unavailable",
    "code": "service_unavailable"
  }
}
```

**Common Causes:**
- Server maintenance
- All providers unavailable
- Circuit breaker open

**How to Handle:**
```python
if e.response.status_code == 503:
    # Wait and retry
    time.sleep(30)
    return retry_request()
```

### 504 Gateway Timeout

Request timed out waiting for provider response.

**Example:**
```json
{
  "error": {
    "message": "Request timed out",
    "type": "gateway_timeout",
    "code": "timeout"
  }
}
```

**Common Causes:**
- Provider is slow to respond
- Complex prompt requiring long processing
- Network latency

**How to Handle:**
```python
if e.response.status_code == 504:
    # Retry with shorter response or different model
    payload["max_tokens"] = min(payload.get("max_tokens", 4096), 1000)
    return retry_request()
```

## Error Handling Best Practices

### Python Client

<CodeGroup>

```python Python
import time
import requests
from typing import Any

class PathfinderError(Exception):
    def __init__(self, status_code: int, error: dict):
        self.status_code = status_code
        self.message = error.get("message", "Unknown error")
        self.type = error.get("type", "unknown")
        self.code = error.get("code", "unknown")
        super().__init__(self.message)


def pathfinder_request(
    url: str,
    payload: dict,
    api_key: str,
    max_retries: int = 3,
    base_delay: float = 1.0
) -> dict[str, Any]:
    """Make a request to Pathfinder with retry logic."""

    for attempt in range(max_retries):
        try:
            response = requests.post(
                url,
                headers={
                    "Content-Type": "application/json",
                    "X-API-Key": api_key
                },
                json=payload,
                timeout=120
            )
            response.raise_for_status()
            return response.json()

        except requests.HTTPError as e:
            status_code = e.response.status_code
            try:
                error = e.response.json().get("error", {})
            except:
                error = {"message": str(e)}

            # Don't retry client errors (except rate limits)
            if 400 <= status_code < 500 and status_code != 429:
                raise PathfinderError(status_code, error)

            # Rate limit: wait and retry
            if status_code == 429:
                retry_after = int(e.response.headers.get("Retry-After", 60))
                time.sleep(retry_after)
                continue

            # Server errors: exponential backoff
            if status_code >= 500:
                delay = base_delay * (2 ** attempt)
                time.sleep(delay)
                continue

        except requests.Timeout:
            # Timeout: retry with backoff
            delay = base_delay * (2 ** attempt)
            time.sleep(delay)
            continue

        except requests.ConnectionError:
            # Network error: retry with backoff
            delay = base_delay * (2 ** attempt)
            time.sleep(delay)
            continue

    raise PathfinderError(500, {"message": "Max retries exceeded"})


# Usage
try:
    result = pathfinder_request(
        url="https://api.dev.pathfinder.naivana.io/v1/chat/completions",
        payload={"model": "auto", "messages": [{"role": "user", "content": "Hello"}]},
        api_key="pk_test_xxx"
    )
    print(result["choices"][0]["message"]["content"])

except PathfinderError as e:
    if e.code == "invalid_api_key":
        print("Please check your API key")
    elif e.code == "rate_limited":
        print("Too many requests. Please slow down.")
    else:
        print(f"Error ({e.code}): {e.message}")
```

### JavaScript Client

<CodeGroup>

```javascript JavaScript
class PathfinderError extends Error {
  constructor(statusCode, error) {
    super(error.message || 'Unknown error');
    this.statusCode = statusCode;
    this.type = error.type || 'unknown';
    this.code = error.code || 'unknown';
    this.name = 'PathfinderError';
  }
}

async function pathfinderRequest(url, payload, apiKey, options = {}) {
  const { maxRetries = 3, baseDelay = 1000 } = options;

  for (let attempt = 0; attempt < maxRetries; attempt++) {
    try {
      const response = await fetch(url, {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'X-API-Key': apiKey
        },
        body: JSON.stringify(payload)
      });

      if (response.ok) {
        return await response.json();
      }

      const errorData = await response.json().catch(() => ({}));
      const error = errorData.error || errorData;
      const statusCode = response.status;

      // Don't retry client errors (except rate limits)
      if (statusCode >= 400 && statusCode < 500 && statusCode !== 429) {
        throw new PathfinderError(statusCode, error);
      }

      // Rate limit: wait and retry
      if (statusCode === 429) {
        const retryAfter = parseInt(response.headers.get('Retry-After') || '60', 10);
        await new Promise(r => setTimeout(r, retryAfter * 1000));
        continue;
      }

      // Server errors: exponential backoff
      if (statusCode >= 500) {
        const delay = baseDelay * Math.pow(2, attempt);
        await new Promise(r => setTimeout(r, delay));
        continue;
      }

    } catch (e) {
      if (e instanceof PathfinderError) throw e;

      // Network error: retry with backoff
      const delay = baseDelay * Math.pow(2, attempt);
      await new Promise(r => setTimeout(r, delay));
    }
  }

  throw new PathfinderError(500, { message: 'Max retries exceeded' });
}

// Usage
try {
  const result = await pathfinderRequest(
    'https://api.dev.pathfinder.naivana.io/v1/chat/completions',
    { model: 'auto', messages: [{ role: 'user', content: 'Hello' }] },
    'pk_test_xxx'
  );
  console.log(result.choices[0].message.content);

} catch (e) {
  if (e instanceof PathfinderError) {
    if (e.code === 'invalid_api_key') {
      console.log('Please check your API key');
    } else if (e.code === 'rate_limited') {
      console.log('Too many requests. Please slow down.');
    } else {
      console.log(`Error (${e.code}): ${e.message}`);
    }
  } else {
    console.log('Unexpected error:', e);
  }
}
```

## Error Code Reference

| Status | Type | Code | Description | Retry? |
|--------|------|------|-------------|--------|
| 400 | invalid_request | invalid_model | Model not found | No |
| 400 | invalid_request | invalid_request | Malformed request | No |
| 401 | invalid_api_key | invalid_api_key | Invalid API key | No |
| 401 | invalid_api_key | api_key_expired | API key expired | No |
| 401 | authentication_error | invalid_token | Invalid JWT | No (refresh) |
| 403 | forbidden | insufficient_permissions | Access denied | No |
| 404 | not_found | resource_not_found | Resource missing | No |
| 422 | validation_error | validation_failed | Invalid input | No |
| 429 | rate_limit_exceeded | rate_limited | Too many requests | Yes |
| 500 | internal_error | internal_error | Server error | Yes |
