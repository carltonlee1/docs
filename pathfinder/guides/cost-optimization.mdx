## Overview

Pathfinder provides powerful routing controls to optimize your LLM costs while maintaining quality. This guide covers routing policies, cost constraints, provider preferences, and model selection strategies.

## Routing Policies

Use the `routing.policy` parameter to control how Pathfinder selects models:

| Policy | Description | Use Case |
|--------|-------------|----------|
| `cost_optimized` | Selects the cheapest capable model | High-volume, cost-sensitive workloads |
| `quality_first` | Selects the highest quality model | Complex reasoning, critical tasks |
| `latency_first` | Selects the fastest model | Real-time applications |
| `balanced` | Balances cost, quality, and latency | General use (default) |

### Example 2: Cost-Aware Chatbot

```javascript
class CostAwareChatbot {
  constructor(apiKey, monthlyBudget = 1000) {
    this.apiKey = apiKey;
    this.monthlyBudget = monthlyBudget;
    this.baseUrl = 'https://api.dev.pathfinder.naivana.io';
  }

  async getMonthlySpend() {
    const response = await fetch(
      `${this.baseUrl}/api/v1/dashboard/spending/summary`,
      {
        headers: {
          'Authorization': `Bearer ${this.accessToken}`
        }
      }
    );
    const data = await response.json();
    return data.total_spend || 0;
  }

  async chat(message) {
    const monthlySpend = await this.getMonthlySpend();
    const budgetRemaining = this.monthlyBudget - monthlySpend;
    const budgetRatio = monthlySpend / this.monthlyBudget;

    // Adjust routing based on budget
    let routing;
    if (budgetRatio > 0.9) {
      // Critical: use cheapest models only
      routing = {
        policy: 'cost_optimized',
        max_cost_usd: 0.0005,
        preferred_providers: ['google']
      };
    } else if (budgetRatio > 0.7) {
      // Warning: prefer cheaper models
      routing = {
        policy: 'cost_optimized',
        max_cost_usd: 0.002
      };
    } else {
      // Normal: balanced approach
      routing = {
        policy: 'balanced',
        max_cost_usd: 0.01
      };
    }

    const response = await fetch(`${this.baseUrl}/v1/chat/completions`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'X-API-Key': this.apiKey
      },
      body: JSON.stringify({
        model: 'auto',
        messages: [{ role: 'user', content: message }],
        routing
      })
    });

    const result = await response.json();

    console.log(`Budget: ${budgetRatio * 100}% used`);
    console.log(`Request cost: $${result.pathfinder.cost_usd}`);
    console.log(`Model: ${result.pathfinder.model}`);

    return result;
  }
}

// Usage
const chatbot = new CostAwareChatbot('your-api-key', 1000);
const response = await chatbot.chat('Hello, how are you?');
```

  </Accordion>

  </Accordion>
