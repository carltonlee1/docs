## Quickstart

Pathfinder is **100% OpenAI-compatible**. Just change your base URL and you're done! Let's make your first API call in less than 5 minutes.

### Prerequisites

You need:
- An API key (get one [here](https://dashboard.pathfinder.naivana.io/api-keys))
- Python, Node.js, or cURL

### Step 1: Get Your API Key

1. Go to [dashboard.pathfinder.naivana.io](https://dashboard.pathfinder.naivana.io)
2. Navigate to **API Keys**
3. Click **Create New Key**
4. Copy the key (starts with `pk_live_` or `pk_test_`)

<Warning>
Keep your API key secret! Never commit it to Git or share it publicly.
</Warning>

### Step 2: Make Your First Request

Choose your preferred method:

<Tabs>
  <Tab title="Python (OpenAI SDK)">
    ```python
    from openai import OpenAI

    # Just change the base URL - everything else stays the same!
    client = OpenAI(
        base_url="https://api.pathfinder.naivana.io/v1",
        api_key="pk_live_YOUR_API_KEY"
    )

    response = client.chat.completions.create(
        model="auto",  # Let Pathfinder choose the best model
        messages=[
            {"role": "user", "content": "Write a Python function to check if a number is prime"}
        ]
    )

    print(response.choices[0].message.content)
    print(f"\nProvider: {response.pathfinder.provider}")
    print(f"Model: {response.pathfinder.model}")
    print(f"Cost: ${response.pathfinder.cost_usd:.6f}")
    ```
  </Tab>

  <Tab title="Node.js (OpenAI SDK)">
    ```javascript
    import OpenAI from 'openai';

    // Just change the base URL - everything else stays the same!
    const client = new OpenAI({
      baseURL: 'https://api.pathfinder.naivana.io/v1',
      apiKey: 'pk_live_YOUR_API_KEY'
    });

    const response = await client.chat.completions.create({
      model: 'auto',  // Let Pathfinder choose the best model
      messages: [
        { role: 'user', content: 'Write a Python function to check if a number is prime' }
      ]
    });

    console.log(response.choices[0].message.content);
    console.log(`\nProvider: ${response.pathfinder.provider}`);
    console.log(`Model: ${response.pathfinder.model}`);
    console.log(`Cost: $${response.pathfinder.cost_usd.toFixed(6)}`);
    ```
  </Tab>

  <Tab title="cURL">
    ```bash
    curl -X POST https://api.pathfinder.naivana.io/v1/chat/completions \
      -H "Content-Type: application/json" \
      -H "X-API-Key: pk_live_YOUR_API_KEY" \
      -d '{
        "model": "auto",
        "messages": [
          {"role": "user", "content": "Write a Python function to check if a number is prime"}
        ]
      }'
    ```
  </Tab>

  <Tab title="Postman">
    1. Create a new POST request
    2. URL: `https://api.pathfinder.naivana.io/v1/chat/completions`
    3. Headers tab:
       - Key: `X-API-Key`
       - Value: `pk_live_YOUR_API_KEY`
    4. Body tab (raw JSON):
       ```json
       {
         "model": "auto",
         "messages": [
           {"role": "user", "content": "Write a Python function to check if a number is prime"}
         ]
       }
       ```
    5. Click **Send**
  </Tab>
</Tabs>

### Step 3: Read the Response

You'll get back a standard OpenAI response with an additional `pathfinder` metadata object:

```json
{
  "id": "chatcmpl-abc123",
  "object": "chat.completion",
  "created": 1704067200,
  "model": "claude-sonnet-4-5",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Here's a Python function to check if a number is prime:\n\n```python\ndef is_prime(n):\n    if n < 2:\n        return False\n    for i in range(2, int(n**0.5) + 1):\n        if n % i == 0:\n            return False\n    return True\n```"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 15,
    "completion_tokens": 89,
    "total_tokens": 104
  },
  "pathfinder": {
    "provider": "anthropic",
    "model": "claude-sonnet-4-5-20250929",
    "cost_usd": 0.001778,
    "routing_decision_id": "dec_abc123xyz",
    "routing_latency_ms": 2.4,
    "completion_latency_ms": 847,
    "confidence": 0.92,
    "fallback_used": false,
    "key_source": "pathfinder"
  }
}
```

**What the `pathfinder` object tells you:**

| Field | Meaning |
|-------|---------|
| `provider` | Which AI provider served this request (anthropic, openai, google) |
| `model` | The exact model used |
| `cost_usd` | Actual cost in USD for this request |
| `routing_decision_id` | Unique ID for tracking and debugging |
| `routing_latency_ms` | Time spent making the routing decision |
| `completion_latency_ms` | Time spent waiting for the LLM response |
| `confidence` | Routing confidence (0.0 = uncertain, 1.0 = very confident) |
| `key_source` | Whether Pathfinder used your keys ("own") or ours ("pathfinder") |

### That's It! 🎉

You've successfully made an API call! Pathfinder:
1. ✅ Received your request
2. ✅ Analyzed the prompt and selected the best model (Claude Sonnet 4.5)
3. ✅ Returned the completion with cost tracking

## What's `model: "auto"`?

When you set `model: "auto"`, Pathfinder analyzes your prompt and automatically selects the best model based on:
- **Prompt complexity** - Simple questions get fast, cheap models; complex tasks get powerful models
- **Cost efficiency** - Balances quality with cost
- **Latency requirements** - Optimizes for response time when needed

You can also specify a specific model if you prefer:
```python
model="claude-sonnet-4-5"  # Always use Claude Sonnet 4.5
model="gpt-5.1"            # Always use GPT-5.1
model="gemini-2.5-flash"   # Always use Gemini Flash
```

## Troubleshooting

### "401 Unauthorized"
Your API key is invalid or missing. Check:
- [ ] API key starts with `pk_live_` or `pk_test_`
- [ ] It's in the `X-API-Key` header
- [ ] There are no extra spaces or characters

### "400 Bad Request - Invalid model"
Model not found. Check:
- [ ] Model name is correct (e.g., `claude-sonnet-4-5`, not `claude-4.5-sonnet`)
- [ ] Or use `auto` to let Pathfinder choose
- [ ] See [Models List](/pathfinder/api-reference/models-list) for supported models

### "429 Rate Limited"
You've exceeded your rate limit. Check the `Retry-After` header for when to retry.

### "502 Provider Error"
The upstream provider (OpenAI, Anthropic, Google) returned an error. Check `pathfinder.fallback_used` - Pathfinder may have already retried with a fallback.
